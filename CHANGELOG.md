# Changelog

## 0.3.0 — 2026-10-26

- Consolidate visual conventions and selection conditions into one guide covering data objects, network modules, operators, parameter states, geometry, and temporal or multi-stage relationships.
- Add four vector representations alongside other elements: solid bars, discrete cells, continuous-value cells, and component bars.
- Add a paper-text-to-figure workflow centered on the core mechanism, true dependencies, and visual hierarchy.
- Make reference study conditional on its relevance to the scientific or structural problem; default visual review to the final color figure.
- Add three explicitly requested style options with their existing gallery-derived validation records.
- Retain editable SVG text, real vector mathematics, format-specific deliverables, and the bundled 2,405-asset SVG library.

## 0.2.0 — 2026-10-18

- Bundle 2,405 SVG reference assets, an offline gallery, per-file source/license/hash metadata, and third-party notices and license texts.
- Search the bundled library by default from any working directory; preserve explicit external-library overrides and optional paper-crop inputs.
- Correct legacy CC BY / CC BY-SA tier assignments using the recorded license, while retaining original asset bytes and source metadata.
- Search and visually study local SVG and paper-crop references before new figures or major layout changes, independently of asset-reuse licensing filters.
- Add read-only metadata search for SVG manifests and benchmark batches, plus evidence-based visual conventions and their semantic limits.
- Default text and mathematics to black or dark gray; require a clear information role for colored text.
- Move the A-group typography experiment record out of general guidance and into project history.
- Respect explicit text-only/no-reference requests while preserving scientific, typography and vector-output checks.
- Route deliverables from the user's requested formats: SVG requests produce one PPT-friendly SVG, vector PDF and PNG; create native PPTX only on an explicit PPT request.
- Preserve ordinary SVG text, inline mathematical glyph references and consolidate each formula into a compound path where compatible.
- Require semantic grouping for nodes, matrices, vectors, arrows and formulas, with true native groups for explicitly requested PPTX output.
- Add reusable SVG preparation and PowerPoint workflow guidance; keep generation sources and validation records in private build directories unless requested.
