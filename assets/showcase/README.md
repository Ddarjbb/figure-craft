# FigureCraft Gallery 来源记录

这些案例是 FigureCraft 工作流生成的结构图和机制图。

| 案例 | 内容依据 |
| --- | --- |
| Stable Diffusion | [Rombach 等，CVPR 2022](https://arxiv.org/abs/2112.10752) · [CompVis Stable Diffusion](https://github.com/CompVis/stable-diffusion) |
| Flow Matching | [Lipman 等，ICLR 2023](https://arxiv.org/abs/2210.02747) |
| AlexNet | [Krizhevsky 等，NeurIPS 2012](https://papers.nips.cc/paper_files/paper/2012/hash/c399862d3b9d6b76c8436e924a68c45b-Abstract.html) |

| Radix-2 FFT | 8 点、按时间抽取的基 2 蝶形运算示意 |
