# Third-party notices

The FigureCraft code and original documentation are MIT licensed. The SVG files in this directory are a collection of separate third-party works; they retain their original licenses and are not relicensed as MIT.

`manifest.csv` is the per-file attribution ledger: file name/title, author, source, source page, original asset URL, license, license URL, SHA-256 and structural flags. Preserve this ledger with redistribution of the collection. When sharing an individual file, preserve its author/source/license information with that file. All SVG bytes are unchanged from the recorded local snapshot. Packaging changes only metadata tier classification, documentation and browsing tools.

- **CC BY** files require attribution and the applicable license link; identify changes when adapting them. Versions 2.0, 2.5, 3.0 and 4.0 are recorded individually in the manifest.
- **CC BY-SA** files retain their recorded version and ShareAlike obligations for adaptations. This collection does not apply ShareAlike to FigureCraft's separate code.
- **MIT** files retain copyright and permission notices. Upstream Devicon and Tabler notices are in `licenses/`; Bioicons notices and author-folder information are preserved under `licenses/bioicons/bioicons/`. Wikimedia MIT authors are named per file in the manifest; the standard permission text is included below.
- **Apache/Pictogrammers** files retain the upstream license texts in `licenses/`. Pictogrammers' text also refers to individually applicable licenses. Source links and authors remain in the ledger.
- **CC0/public-domain** entries retain their source and status; this is not a trademark or endorsement license.

The convenience tiers are not complete license terms. T1 includes MIT and Apache notices, which must still be retained. CC BY is T2 and CC BY-SA is T3. Asset-reuse decisions use the original license, not the tier alone. Observation/reference search does not filter by tier by default.
