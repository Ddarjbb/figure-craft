# 科研图的色彩规范与选择条件

适用于方法图、模型结构图、技术路线图、统计图与多子图的配色。先确定颜色承担的信息，再选择色板。用户明确指定的颜色与目标出版方的实际要求优先；主技能的文字颜色、最终彩色验收和交付规则继续适用。

## 颜色先有职责

- **类别**：区分方法、实验组、模态、对象或阶段。
- **数量**：表达大小、强度、概率、距离或相对基准的偏差。
- **状态**：区分选中、替换、保留、冻结、可训练等已定义状态。
- **强调**：引导读者注意核心路径或比较，其余信息降低视觉权重。

同一对象跨子图沿用同一映射。不同概念可以共享中性底色，但不能在同一解码范围内用同一种关键颜色表达相互冲突的含义。颜色与位置、名称、线型或形状协同表达。

## 色彩角色与层级

| 角色 | 默认处理 | 选择条件 |
|---|---|---|
| 画布 | 白色或中性背景 | 让对象边界、数据与文字清楚；背景本身不承担无必要的强调。 |
| 普通文字、公式、坐标与图例文字 | 黑色或深灰，例如 `#202124` | 同层级保持一致；浅底模块不自动使用彩色文字。深底时可用反白文字。 |
| 模块与作用域填充 | 适度低饱和、浅色填充 | 用于分组，保证其上的文字与边界清楚；不靠整片强色抢占主线。 |
| 数据线、点与关键边界 | 在实际尺寸下有足够对比的颜色 | 小点和细线可比大面积填充更深；不能把浅色背景色直接当作数据线色。 |
| 误差带、置信带与次级区域 | 与对应对象同色系的浅色或透明填充 | 主线清楚可见，区间定义由图例或 caption 交代。浅色填充与透明度二者按渲染效果选择。 |
| 核心机制或重点对象 | 少量强调色、较深轮廓或更明确的线宽 | 颜色强调与科学重点对应，避免给所有模块同等强烈的强调。 |
| 参考对象或上下文 | 中性灰或降低饱和度 | 降低视觉权重仍须可读；若是重要比较组，不应淡化到难以辨认。 |

普通标签与数学默认灰黑。彩色文字只用于明确的对应、状态或关键比较；检查其颜色是否帮助读者作判断。[Nature 图形指南](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)采用色块配黑色图例文字，并强调可访问性；具体投稿仍按对应出版方执行。

## 按数据语义选择色板

| 数据／对象关系 | 色板类型 | 使用要点 |
|---|---|---|
| 无天然顺序的类别 | 定性色板 | 色相清楚分离；不通过渐变暗示不存在的大小或顺序。 |
| 从低到高的连续量 | 顺序色图 | 优先采用感知变化平稳、明度有序的映射，如 `viridis`、`cividis`、`magma`。明确色条、范围与单位。 |
| 围绕零、基准或其他有意义中点的偏差 | 发散色图 | 明确中点及其归一化位置，定义两侧含义；不能默认把不对称数据范围的中心当作零。 |
| 相位、角度等首尾相接的量 | 循环色图 | 首尾颜色衔接，避免在相等状态处制造人为断裂，如适用时选择 `twilight`。 |

上述分类与色图特性可查 [Matplotlib 色图选择文档](https://matplotlib.org/stable/users/explain/colors/colormaps.html)。色图名只是起点，最终仍要检查归一化、背景与目标尺寸。对一般连续数值，避免默认采用会产生不均匀感知变化的 `jet`／彩虹色阶；离散类别使用多个色相则是另一种编码任务。

## 按图型应用

| 图型 | 配色组织 | 需要保持的关系 |
|---|---|---|
| 方法图、模型结构图、pipeline | 以职责、模态或阶段分组，浅填充配深色文字，核心路径适度强调 | 同一角色保持一致；同色、同名或对称布局本身不能证明参数共享。 |
| 分组柱状图、箱线图、散点比较 | 按实验组固定映射，结合图例、位置或点型 | 冷色对照、暖色实验是一种可选约定；不能用冷暖替代明确组名，也不预设某组更好。 |
| 折线图、趋势与消融 | 类别色配实线／虚线、点型或直接标签，主要比较清楚突出 | 不仅靠色差区分曲线；线、点、误差带沿用同一对象映射。 |
| UMAP／t-SNE 分类散点 | 按真实类别使用定性色，必要时直接标注类别或编号 | 类别增多时优先考虑分面、可解释分组、标签或交互；只有真实层级存在时才用同色系表达层级。 |
| FeaturePlot、表达强度、概率或注意力数值 | 按数值语义选顺序或发散色图，配色条 | 非负表达量通常用顺序图；正负偏差用有定义中点的发散图；二值访问 mask 采用离散状态色。 |
| 气泡图 | 分开定义位置、大小、颜色与透明度的职责 | 类别与数量使用各自映射；不把多个视觉通道无定义地混用。 |
| 热图与多子图 | 同一比较口径使用一致色图与数值范围 | 各图独立归一化、截断或采用分位数时明确交代；视觉上相同的颜色不能被误读为相同绝对值。 |

高密度散点可用透明度减少遮挡，需同时考虑绘制顺序和类别覆盖。不要通过改变某组透明度、深浅或渲染顺序制造更强的分离或显著性印象。

## 克制用色的适用范围

- **主色 2–3 个**可作为简单结构图或少组比较的起点，不是类别数量上限。实际有更多需要区分的类别时，按信息需要扩展。
- **低饱和**适合模块填充或次级区域；细线、小点、边界与重点标记需要足够对比。清晰度优先于统一的浅色观感。
- **6:3:1**可作为主次与强调的构图启发，不作为数据比例、颜色数量、绘图面积或验收指标。
- **多类别不自动改渐变**。无序类别使用同色渐变可能暗示顺序，也可能降低可分性；应根据真实类别关系决定。
- **不从示例外观推导出版规范**。具体出版方是否要求某种色彩空间、颜色组合或检查方式，以其当前官方要求为准。

## 可选色板

以下 HEX 来自用户提供截图中的文字标注，按标注录入，不从 JPEG 像素反推原始颜色。它们是可选起点，不是官方期刊色卡，也未据截图完成色觉可访问性或感知均匀性验证。只取当前任务需要的颜色，不要求整组使用。

| 色板 | HEX 色值 | 适用起点与选择条件 |
|---|---|---|
| 蓝—粉—浅蓝与紫色扩展 | `#4F587D`、`#C68DC0`、`#C2E0EE`、`#776B97`、`#DBC8ED` | 可用于少量类别或模块分组。浅蓝和浅紫更适合填充或较大标记；深蓝与紫色也要检查相互区分。 |
| 冷暖连续候选节点 | `#5271AE`、`#70ACDE`、`#F5CC7D`、`#FFA660`、`#D85B59` | 可作自定义色图的候选节点；不因颜色依次变化就认定为感知均匀的顺序图。用于连续量前检查明度与归一化；用于偏差图时明确中点。 |
| 柔和多组强调 | `#DBA3B4`、`#ACD1BE`、`#D3B0DE`、`#A7B8DB` | 可用于类别填充、气泡或局部强调。密集重叠、细线或小点场景须检查可分性，必要时配较深轮廓。 |
| 蓝紫—青绿双组 | 主色 `#8D9FCD`、`#62BE9F`；浅填充 `#DBE1EC`、`#D0EEE4` | 可作双组比较与对应浅色带的起点。主线、点与浅色带建立一致对应；不要重复叠加透明度导致填充过淡。 |

确定映射后，保存对象名称与 HEX／色图名称；同一对象跨面板、曲线、标记和图例复用该映射。若为提高可读性另选更深的线色，保持同组线与填充的对应并统一应用。

## 色觉可访问性与最终检查

颜色承担关键区分时，同时提供名称、位置、线型或点型等辅助信息。红—绿组合尤其需要谨慎；蓝—橙、蓝—黄也不是无需核对的可访问性保证。必要时结合色觉模拟检查实际成图。[Nature 图形指南](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)提供了红绿难辨与保留对比的对照示例。

默认检查最终彩色成图，不因配色参考提到灰度而自动生成灰度预览。用户明确要求灰度交付或目标出版方明确要求相应检查时，再针对该任务处理。灰度可辨与色觉可访问性是不同检查，不能互相替代。

交付前在实际插入尺寸核对：

1. 每种关键颜色的对象、数值或状态含义明确，跨图映射一致。
2. 普通文字、公式、坐标与图例可读；浅色填充不会吞掉小点、细线和边界。
3. 类别色与连续色的类型正确，关键差异还有颜色之外的识别依据。
4. 数值色条、范围、中点、归一化及跨图比较口径正确。
5. 渲染后的透明度、重叠、背景和导出色彩空间符合当前任务。
