# 机制驱动的构图选择

用于新建或大幅重构方法图、模型图和技术路线图。先用一句话说清**什么对象发生了什么变化，读者需要看出哪项关系**。据此决定图上哪个形状最先被看见，视线接着往哪走。显式布局、目标版幅和同篇论文的视觉约定优先。

## 让对象的关系决定画法

按图要回答的问题挑一种主构图。先布置有意义的对象、状态或对照，让位置和形状承担部分解释。

- **让排布说明关系。** 同一个对象的不同状态可以占用共享的行、坐标或时间轴；选择、替换和变换可以直接画在对应位置。把算子、短标签和必要公式贴在它们作用的对象或发生变化的位置。
- **让例子兼任流程。** 例子中的输入、变化和结果已经构成主线时，用同一组图形承载方法步骤。共享输入、条件或尺度可以只放一次，辅助机制可嵌在相关状态旁。必要时用局部放大补充细节。
- **先画读者需要识别的模块边界。** 当多个子步骤和对象共同执行一个阶段、机制或迭代时，用清晰外框把它们收在同一范围内，标题靠边，输入输出落在明确的边缘位置。内部以对象、排列和短标签组织；有独立子范围、分支或局部展开时，嵌在所属的大范围内。单独的名称或变量可贴近对象。
- **让不同形状承担不同内容。** 数据可以画成队列、条带、矩阵、叠片或图节点；状态变化可以用对齐的对象、并排比较、分数条或轨迹。结构与变化先在形状和位置中画清，再加入方向、步骤和必要标注。
- **把跨边界的连线收在接口处。** 内部连线留在所属范围内，跨区的线贴着模块入口和出口走。多个子步骤共用的一项输入可从一个接口进入再分配。让标题、标签和框线之间留有清晰间距。
- **同图混用有不同职责的边界。** 当图中有多层或多种边界时，组合使用实线框、虚线框及适合对象的轮廓。范围框以方角、无填充起稿，可用深色实线围住主模块，用较轻的虚线围住内部子过程或放大区。底色用于区分需要辨认的状态、类别或重点，局部色块随所标对象放置。
- **按用途选形状。** 步骤名、公式和变量先试开放标注、分隔线或括号。圆角适合有具体外形的对象、部分数据标记或有依据的视觉约定；模块外框、子过程边界、数值格和标签各自决定角形、描边和填充。绘制时分别指定这些属性，让共用的矩形绘制函数支持各自的选择。

| 图要回答的问题 | 可采用的构图 | 最先让读者看见 |
| --- | --- | --- |
| 张量在空间、尺度或秩上怎样变化？ | 画对象的轮廓、尺寸和对应位置。用网格、条带、矩阵或特征层表达变换。 | 尺度变化、对应的 patch、同尺度连接或低秩瓶颈 |
| 方法改了基线的哪一部分？ | 并排对齐同一对象。共享部分沿用形状和位置，把强调色给发生变化的部位。 | 新增、替换或冻结的部分，以及汇合位置 |
| 状态怎样一步步更新？ | 画同一对象的几个关键时刻。保持坐标或身份对应，把操作贴在发生变化的位置。 | 某个窗口如何移动、哪些元素被保留或替换 |
| 一个局部操作怎样改变全局？ | 用紧凑总览定位该操作，再局部放大。让主机制的几何结构承担重点。 | 活动 tile、选中的邻域、条件注入点或核心算子 |
| 哪些数据或状态跨越边界？ | 按真实的设备、内存、角色或阶段划分空间。把传输、读写和回路画在边界上。 | 跨边界的对象、流向和共享状态 |
| 处理顺序或多组件协作就是主线？ | 使用分支流程、泳道、层级结构或可复用模块。只有承担组织作用的层级才用外框。 | 主路径、关键分支以及汇入或反馈处 |

同一个模型可以有不同画法。问 Swin Transformer 的整体结构时，可以突出逐阶段缩小的特征网格。问 shifted window 时，把同一网格的两个窗口划分并排，第一眼就能看到边界移动。主题只限定科学对象，读者的问题决定这张图的构图。

## 先排主次与从属关系

- **版幅跟着机制走。** 单一操作可以做成单栏或紧凑竖图。对齐比较、分块坐标或跨域关系确实需要横向空间时用通栏。
- **先给核心机制连续的空间。** 在构图草图中先放下最能解释贡献的对象、对照或状态变化，确定它从哪里开始、读到哪里结束。用相对面积、位置、形状或对比让这段关系成为读者第一眼看到的内容。连续变化可以由共享坐标或一段相邻的状态序列承载。
- **让支撑过程有明确归属。** 把提供条件、学习参数或执行更新的过程放在它实际支撑的对象、分支或转折处，可用邻近小组、侧栏或局部展开。需要在同一范围内解读的内容，用共享对齐、留白、分隔或边界组织在一起。根据它们对读者理解的作用分配面积和对比。
- **把细节放在深入阅读的位置。** 算子、变量和图例靠近所属对象。总览中用可见的变化、短标签和符号解释操作；遇到确需等式说明的关键关系，把等式靠近该处。训练、推理等标题标明范围，具体画面权重由科学重点决定。
- **让视觉变化有含义。** 矩阵的长窄、网格的相对位置或重叠关系可以承担含义。颜色可以对应类别、状态、方向或当前关注项，具体色板按[配色指南](COLOR.md)选择。框、箭头和模块名称用于补清逻辑。
- **控制跨图复用。** 同篇论文保持字体、符号和对象配色的一致。多张独立题材各自选择视觉主角和阅读路径。如果把上一张的对象名称换掉就能沿用整套版式，检查是否漏画了当前机制特有的对象关系。关系确实相同时可以复用构图。

## 用最终尺寸检验读图顺序

在目标插入尺寸看彩色成图，暂时略读标签与公式。按读者的顺序检查三件事。

1. **第一眼**看到的对象、差异或变化能否对应核心机制？
2. **顺着看**能否分出主模块、内部子过程和跨区接口？每种边界的线型、轮廓和填充是否帮助辨认其职责？
3. **细读时**线、变量与图例是否清楚且靠近所属对象？逐条查看独立等式，保留读懂图形所需的关键关系。

若阶段标题、外框或支持公式抢占第一眼，先调整区域大小和位置，把依赖放回它作用的地方，再调线条和色彩。按外层模块、内部子范围和具体对象检查边界。确认实线、虚线、方角、圆角和色块各有用途。若同一款带底色圆角框同时包住各层模块、数值格和短标签，先将范围改回中性边界，把短标签贴回对象，再给需要区分的状态或对象加色。恢复正常阅读后核对科学语义和可读性。参考图按[参考图检索与学习](REFERENCE_STUDY.md)的相关性条件选用。
