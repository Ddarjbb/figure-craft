# 外部图标来源与使用

本规则适用于论文图中的语义 icon：文档、用户、机器人、素材、设备、状态等用于快速识别对象的图形。是否使用 icon 由它能否帮助解读决定。

## 来源要求

**禁止自绘 icon；必须使用现有外部图标库的资产。** 不得手工绘制、用 SVG／Python／CSS 等代码拼画、描摹重画或使用生成模型制作替代图标。随包图库中具有明确外部来源和许可的 icon 可直接选用；它们仍按外部资产管理。

矩阵、向量、网络层级、图结构、时间轴、统计曲线与真实模块连接是依据科学内容绘制的结构或数据表达。它们继续按视觉惯例制作；文档轮廓、人物、机器人、胶片、设备等识别性图标不能借“结构示意”之名自绘。

## 选择与记录

- 根据对象语义和版面选择同一风格体系的矢量资产。可从 [Lucide](https://lucide.dev/icons/) 或 [Tabler Icons](https://tabler.io/icons) 等库检索，不将任何一个库设为唯一选择。
- 在嵌入前核对所选资产当前的官方许可和署名要求；同时检查随库附带的上游声明，不能仅凭库名或网页页脚推断许可。
- 保存库名、图标名、官方来源链接、固定版本／提交或下载日期、原始 SVG、文件哈希及许可文本。可以合并为构建目录中的一份来源清单，不为每个图标另建文档。
- 保留许可要求的版权、许可与署名信息。按使用方式放入随附 notice、文件元数据或文档所需署名位置；不默认在图内增加细小的来源声明。
- 找不到语义或风格合适的图标时，换用其他有明确许可的库，或保留清楚的文字标签。不得回退到自绘图标，也不因图标缺失停止本可继续完成的绘图任务。

## 允许的调整与嵌入

- 可按许可调整尺寸、颜色、线宽、位置及整体旋转，并统一同层级的视觉重量。保留库内原始几何；不补画、重画或组合新轮廓来制造新图标。
- 将实际矢量几何嵌入 SVG、PDF 或原生矢量交付物。仅用 CDN 链接、外部 `<image>`、图标字体或远程 `<use>` 引用，不能代替可独立打开的最终图。
- 图标保持矢量。SVG 按“图标 + 标签／所属对象”语义分组，保留普通文字可编辑；原生 PPT 按相应交付流程处理。
- 导入库内 SVG 时保留 viewBox、比例、线帽和连接样式。SVG 像素与 PDF 点的换算需按实际边界核对，防止导出后图标大小或位置变化。

## 验收

检查来源清单和原文件能否对应到每个图标，所需声明是否随交付物保留，几何是否仍来自库内资产。以最终尺寸检查识别度、文字间距、线宽、裁切、遮挡和各导出格式的一致性。

现有 SVG／PDF 结构检查可以确认矢量和字体等属性，不能自动证明图标来源；来源与几何对应关系必须单独核对。
