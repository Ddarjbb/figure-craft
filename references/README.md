# 计算机领域论文插图指南索引

核对日期：2026-10-16（Asia/Hong_Kong）。适用对象：论文正文中的方法图、架构图、技术路线图与实验图；不适用于海报、演讲幻灯片或视频。

先读 [GENERAL.md：科研绘图通用规范](GENERAL.md)，再读目标会议指南。通用文件覆盖科学正确性、图形语义、数据统计、最终尺寸可读性、可访问性、可追溯性和验收流程；会议文件补充各自的格式规则。

用户另行指定的公式与字体要求见 [TYPOGRAPHY.md](TYPOGRAPHY.md)：公式／数学符号使用 LaTeX 或 MathJax 等引擎生成衬线数学字形，普通标签与 Times New Roman 按角色组合。这是本项目要求。

图内标题、标注与 caption 遵循 [ANTI_DEFENSIVE_FIGURES.md](ANTI_DEFENSIVE_FIGURES.md)：围绕成立的机制与价值组织画面，用对象职责和阶段归属表达科学信息；解释性小字声明移入正文，图内保留必要标签、核心公式与图例。

按输入选择路径：草图出图和一句话绘制知名模型沿用主 skill；根据论文原文制作框架图／技术路线图时，先读 [Text-to-figure guide](text-to-figure.md)，确定图的主张与视觉重心。参考图仅在高度相关时选用，默认不生成或检查灰度预览。

## 如何解释规则

- **官方明确规范**：官方指南或模板写明的格式指令；保留其具体适用范围。出现 should、encouraged 等措辞时，不升级为 must。
- **官方建议**：官方明确建议的可读性、无障碍与图形选择实践。
- **本项目绘图实践**：为了执行规范所采取的设计方法，不是会议额外发布的规定。
- **未确认**：本次核对未找到明文数值；不能理解为无限制，也不能自行补出阈值。
- 各文件均保留来源。适用年份主要为 2026；ACLPUB、ACM 与 SIGACCESS 属于持续更新的通用资料。
- 同一年中，具体 track／终稿的最新明确通知优先于通用模板中陈旧文字；跨年使用须复核。记录冲突，不能静默拼接出一套不存在的规则。

## 后续任务的执行流程

1. 识别目标会议、年份、track、审稿稿或终稿，以及需要单栏图还是通栏图。用户未指定时，先做可重排矢量源稿，不宣称全会议通用合规。
2. 读取对应会议指南，再检查用户提供的正式模板及其更新；不把 IEEE 通用规范替代会议自己的规范。
3. 先定图要传达的科学信息，再定最终插入宽度、字号、线宽和布局。方法图突出数据流和训练／推理关系；实验图交代坐标、单位与曲线身份。
4. 原生矢量技术路线图保留 SVG 等可编辑源文件，论文排版通常导出矢量 PDF。用户要求矢量且禁止 imagegen 时，直接用代码或矢量绘图工具实现。
5. 在真实模板中编译并按实际尺寸检查。普通标签字号与数学上下标分开评估，不能仅凭生成脚本的 font-size 宣称最终可读。
6. 验证字体嵌入、位图与色彩空间、边界框、标签和连线是否遮挡；检查实际彩色渲染，保留预览与可复现源码。

### 缩放核算

最终字号 = 源图名义字号 × 最终插入宽度 / 源图宽度；线宽按同一比例变化。

例如，将 174.625 mm 宽、9 pt 标签的图缩至 139.7 mm，标签会变成 7.2 pt。文件仍是矢量，并不能保证字号合适。矢量线条不以“300 dpi”判断精度；嵌入的照片或栅格热力图则要单独检查有效分辨率。

### 避免误用

- caption 的 9／10 pt 不等于图内标签必须取相同字号。
- “尽可能匹配正文”不等于官方规定了一个独立硬性最低值。
- SVG 是编辑资产，不表示所有会议的编译或生产系统直接接收 SVG。
- 转路径能避免字体替换，但会失去部分文本语义；保留有文字的编辑源稿，按出版流程选择交付方式。
- 字体或颜色规范合格，不代表图的科学表达已经清楚；这两项分别检查。
- (a)–(c)、少量配色、紧凑布局等是可选设计方法，不能包装成所有会议的强制规则。

## 更新方式

更新某一会议文件时，同时修改核对日期与适用年份，保留新增官方来源，并注明被替代的规则。不要仅根据博客、已发表论文的外观、搜索摘要或非官方模板覆盖已确认规定。
