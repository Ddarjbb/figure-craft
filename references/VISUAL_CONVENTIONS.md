# 科研图的视觉惯例与选择条件

按科学对象、真实计算关系、抽象层级与最终尺寸选择结构表达。形状与名称、数学符号及必要维度共同说明对象；同一对象可以采用多种画法，选择取决于图要传达的信息。以下为绘图实践，不是会议强制规范。

## 输入、输出与数据表示

| 对象 | 可选画法 | 选择条件与必要语义 |
|---|---|---|
| 向量：单色长条 | 一根横向或纵向的实心长条，可用轻微圆角，邻近标注向量名称与数学符号，如 $\mathbf e\in\mathbb R^d$ | 适合概览中的抽象 embedding、条件向量或潜向量，强调向量作为整体参与计算。长条的长宽不自动表示维度、范数或数值；通过标签和连接端口将数据对象与计算模块区分。 |
| 向量：离散色块 | 将分量排列为等大的单元格，用少量固定颜色区分离散取值，如 $\mathbf x_0=[0,1,0,1,0]$ | 适合二值交互向量、one-hot、multi-hot 或其他离散分量。颜色对应明确的取值或状态，必要时配数值或图例；格子对应向量分量，与每格代表一个 token 的序列区别表达。 |
| 向量：连续数值色块 | 将分量排列为等大的单元格，用颜色深浅或连续色阶表达数值，如 $\mathbf x_t\in\mathbb R^d$ | 适合连续特征、浮点 embedding 或扩散过程中的带噪向量。定量表达采用一致的数值到颜色映射；有序数值使用顺序色阶，需区分正负时可用以零为中心的发散色阶。纯示意配色不解释为实测数值。 |
| 向量：柱状向量 | 沿基线排列窄柱，以每根柱子的高度表示对应分量，邻近标注向量符号，如 $\mathbf x_t$ | 适合强调各维数值、稀疏性或向量随步骤的变化。保留零基线，负值向基线下方延伸；比较向量时保持分量顺序和数值尺度一致。定量读数所需的索引、刻度与单位按任务补充。 |
| 矩阵、二维数值阵列 | 二维网格、带括号的元素阵列、带色条热图 | 明确行列与数值映射，配名称、数学符号及必要维度；装饰网格不能冒充实测矩阵。 |
| 图像、文档、多视角输入 | 小幅实际样例、纸页轮廓、图像平面或按视角对齐的缩略图组 | 内容或空间对应重要时展示样例；只需识别模态时可用简洁矢量轮廓。视角、样本与处理阶段通过邻近标签区分。 |
| 视频、运动、时序信号 | 横向帧带、错位叠帧、骨架／姿态序列、沿时间轴的窗口块 | 帧序与时间方向明确；滑动窗口、片段边界和跨模态时间对齐由位置及标签表达。叠放本身不定义时间间隔。 |
| 文本、提示与可学习 query | 短文本样例、token 单元序列、独立的 prompt/query 格 | 内容与 token 身份分开；学习得到的 query 与输入文本 token 通过分组和标签区分。 |
| 特征图、CNN 特征张量 | 叠放平面、薄片、简洁长方体、带实际空间布局的特征网格 | 叠片适合表达通道／层级，平面网格适合空间位置；必要时标注真实形状。厚度、透视和可见格子数不自动表示通道数。 |
| patch、token、序列化特征 | 原图分块后接一维 token 格、分组条带、位置对齐的多行格 | 区分空间 patch、token 位置和向量分量。flatten、patch embedding、压缩或重排在转换处标明；保持对象前后对应。 |
| 注意力、相似度与访问掩码 | 数值矩阵／热图、分块矩阵、二值可见性网格 | 先标清行列的对象或 query/key 身份，再定义格子含义。权重值、禁止访问、head 分类与层索引采用各自语义，不能一律画成“attention heatmap”。 |
| 掩码、分割与检测结果 | 二值轮廓图、原图叠色区域、图像—mask 对、选中 patch 格、边界框 | 按像素类别、选择区域、置信度或空间范围选择画法；预测、监督和输入掩码分别标明。保持样例和空间位置对应。 |

## 网络模块与内部机制

| 对象 | 可选画法 | 选择条件与必要语义 |
|---|---|---|
| Encoder / Decoder | 压缩／展开梯形、分辨率阶梯、实际层级的模块串联 | 梯形用于概括映射；空间尺度变化重要时用阶梯并标尺寸；注意力编码器不因名称而套用漏斗。 |
| Autoencoder / 瓶颈 | 编码收缩—潜变量—解码展开，概览可用沙漏形并配名称 | 只有实际存在编码、瓶颈与解码关系才这样画；不能把一般扩散模型当成 U-Net。 |
| CNN、多尺度结构与 U-Net | 多级特征平面／张量块、分支金字塔、下降—瓶颈—上升路径 | 层级、尺度和横向连接对应真实架构。U-Net 画实际 skip 端点与融合算子；不把一般编码解码或扩散模型都画成 U-Net。 |
| MLP、投影与预测头 | 分层神经元及连线、简化层级、与映射职责一致的投影形状 | 解释连接结构时展开层级；概览控制细节并保留结构身份，不暗示一般 MLP 必然降维。 |
| Transformer | 重复 block、单个 block 的局部展开、按模态／时间对齐的模块泳道 | 展开到与贡献有关的 attention、FFN、normalization 或残差操作；严格保留原方法的顺序、连接和 pre/post-norm 位置。重复个数仅在有依据时作实际层数。 |
| Self-/Cross-attention | 标明来源的 Q/K/V 端口、跨流路由、注意力模块与矩阵的对应展开 | 来源和输出决定谁查询谁。self-attention 与 cross-attention 不能仅用颜色区分；跨线本身不代表融合。 |
| MoE、路由与选择 | 显式 router、并列 expert 分支、选中路径和路由权重 | 区分选择、加权汇合和普通并行计算。top-k、稀疏激活、共享 expert 或教师路由仅在方法支持时画出。 |
| Codebook、量化与残差量化 | 带索引的码表、二维排列的码字、最近码字选择、逐级减残差和重建求和 | 离散索引与连续码字分开；表轴定义 code、subspace 或层级。残差更新和求和必须连接到真实对象。 |
| Memory、prototype 与 KV cache | 条目集合／表格、原型缩略图、分区缓存，以及读、写、查询、命中条目的箭头 | 区分存储对象与计算模块；read/write 方向及 cache 的 K/V 身份明确。不能把运行状态缓存、可学习参数和检索库默认视为同类。 |

## 运算、连线与参数状态

| 关系 | 可选画法 | 选择条件与必要语义 |
|---|---|---|
| 求和、乘法、门控、拼接 | 汇合点处的算子节点，或写明 Add、element-wise multiply、MatMul、Concat 的模块 | 符号与实际运算对应；区分逐元素乘法和矩阵乘法。采用参考图的符号时，结合实际方法核实其运算含义。 |
| Flatten、reshape、重排与采样 | 转换前后保留可对应的数据形状，中间放短操作标签 | 尺度、维度、排列或样本选择的变化各自标明；形状变化不应暗示没有发生的学习或信息压缩。 |
| 残差、skip 与跨尺度融合 | 从明确端口绕行的旁路，接入真实算子或目标层 | 分清层内残差与编码解码 skip；共享参数不是 skip。交叉不连接，汇合用接点或算子确认。 |
| 损失、监督与对齐 | 从参与比较的输出和目标接入损失节点，必要时区分监督边 | 显示损失比较什么对象；数据流、监督和梯度各自有定义。损失连线不自动等于反向传播路径。 |
| 参数共享、冻结与可训练状态 | 单个共享模块、多实例间的共享标记、明确文字标签，或配图例的简洁矢量状态符号 | 同色、同名和对称布局都不足以证明共享。冻结不等于停止某条梯度；EMA 更新不等于普通数据流。状态符号配明确图例，并遵守主技能的矢量图标规范。 |
| 图结构 | 数据对象图用实体节点与领域关系边；计算图用模块／算子节点与数据流边 | 先说明节点和边的含义。神经网络层间连线、几何邻接、知识关系和因果边分属不同语义；有向箭头不自动证明因果。 |

## 几何与空间对象

| 对象 | 可选画法 | 选择条件与必要语义 |
|---|---|---|
| 点云、mesh、voxel 与 3D Gaussian | 点集合、网格表面、占据体素、带尺度／朝向的椭圆或椭球核 | 按方法实际操作的表征选择；网格拓扑重要时展开边线。Gaussian 核本体、沿射线的 opacity 曲线和最终渲染图分别表示。 |
| 相机、坐标、射线与投影 | 相机视锥、成像平面、带标签坐标轴、射线与落点、源／目标视图 | 几何箭头与处理流程箭头区分；反射、透射、视角变换等通过路径和标签定义。视锥外形不替代内外参或投影方程。 |
| 对应、配准与匹配 | 对齐视图间的匹配线、源／目标点集、变换前后对象、相似度矩阵 | 说明线表示候选匹配、筛选后匹配或几何变换。颜色、数量和距离若非定量，不解释为精度、概率或真实尺度。 |

## 阶段、时间与阅读顺序

| 关系 | 可选画法 | 选择条件与必要语义 |
|---|---|---|
| 扩散、迭代与循环状态 | 沿步数排列的状态链、带更新算子的循环、主流程加单步展开 | 明确 forward/reverse、时间／噪声方向和条件输入；每一状态的变量对应正文。去噪器预测干净样本、噪声、速度还是分数，按原方法标注。 |
| 因果、流式与自回归 | 对齐时间窗口、分块访问掩码、历史／当前／未来分区、cache 读写与更新 | 顺序、可访问区域和状态寿命由图形表达；普通帧带不能单独证明因果性，分块图也不自动表示量化数值。 |
| 教师学生、训练推理与多阶段 | 对齐泳道、阶段分区、共享模块、训练监督边与推理主路径 | 标出各阶段输入、可更新对象和输出。蒸馏、EMA、预计算特征和运行时传输按实际关系连线；不靠相同颜色暗示共享。 |
| 总览与局部机制 | 总体主线配一个关键机制放大框、按对象对齐的前后对照、必要的并行面板 | 局部展开与总览保持对象身份和端口对应；主次由贡献决定，不把论文小节均分成相同卡片。 |

## 使用时的判断

先确定图中需要追踪的对象，再确定关键操作改变了它的什么属性，最后选择形状和布局：身份用样例／轮廓，分量用向量格或柱，空间位置用网格／几何，跨对象关系用有语义的边，状态变化用时间或阶段排列。一个图中不必用齐所有元素。

结构示意、实际数据可视化和定性结果分别处理。必要尺寸与符号贴近对象；示意数量、抽象范围和设计解释留在正文或制作记录。同一语义与抽象层级下保持表达一致；对象类型或状态变化时，通过形状、分组、阶段标签和真实数据流表达变化。所有画法继续遵守主技能的结构表达、数学排版、文字颜色、矢量编辑与最终尺寸检查要求。
