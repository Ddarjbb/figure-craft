# 科研图的视觉惯例与选择条件

按科学对象、真实计算关系、抽象层级与最终尺寸选择结构表达。以下为设计惯例，不是会议强制规范。

## 形状应帮助读者识别计算角色

| 对象／关系 | 可采用的表达 | 选择条件与语义边界 |
|---|---|---|
| Encoder / Decoder | 沿数据流收缩／扩张的梯形；展开时用尺寸递减／递增的层级 | 适合概括编码解码或压缩重建。外形不自动表示精确压缩率、可逆性或每层尺寸；保持分辨率的 Transformer 不强制套漏斗。 |
| Autoencoder / 瓶颈 | 编码收缩—潜变量—解码展开；概览可用沙漏形并配名称 | 只有实际存在编码、瓶颈与解码关系才这样画，不能把所有扩散模型都当成 U-Net。 |
| MLP / 全连接 | 分层神经元及连线；概览中可用带标签的投影梯形或简化层级 | 神经元图用于说明全连接结构，梯形用于概括映射。若只是一般 MLP，不暗示必然降维；需要示意神经元数时不冒充真实配置。 |
| CNN / 多尺度特征 | 叠放平面、薄片或长方体，配层名与必要维度 | 平面表示空间维度、厚度表示通道时保持一致；装饰透视不代替实际尺寸标注。 |
| 向量、Embedding / token 序列 | 一维单元条带；序列可用重复 token 格与省略号 | 明确单元代表分量还是 token。时间顺序、模态分组和特殊 token 用位置、标签及必要颜色表达，不把两种含义混用。 |
| 矩阵、注意力、二维特征 | 网格、带括号阵列或带色条热图 | 行列、轴与数值含义明确；装饰网格不能冒充真实注意力结果。 |
| U-Net | 下降路径—瓶颈—上升路径，对应尺度之间画真实 skip | 跳连端点及融合算子须对应实现。非对称网络不为外形对称而补层或连线。 |
| 残差、求和、乘法、拼接 | 旁路接入标明算子的节点；拼接单独标识 | 区分加法、逐元素乘法、矩阵乘法与 concat，不用无标签汇合点掩盖运算差异。 |
| 主流程与机制展开 | 总览保留主路径，局部面板展开一个关键模块 | 用名称或引线建立对应；局部层级与主图一致，避免给每个模块都加一张放大卡片。 |
| 多阶段或并行比较 | 阶段分组或对齐泳道，重复对象沿用位置与结构 | 相同布局帮助识别变化。共享参数需明确表示，重复画同名模块本身不能证明共享。 |

形状通常与名称一起使用。选择由本图的科学主线、抽象层级和版面决定；一个对象可以有多种有效画法。参考图中的彩色文字、emoji、渐变或阴影不作为默认风格继承。
