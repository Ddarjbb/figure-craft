# P2｜开放对象机制

用户明确指定 P2 或要求使用本风格时读取。证据与局限见[验证记录](validation.md#p2)。

## 从图片提炼的特征

提炼主例为 D26 Graph Generation with Diffusion Mixture、D27 Exploiting Code Symmetries（均为 ICML 2024）和 D34 Fourier Neural Operator: A Mean-Field Perspective（NeurIPS 2024）。图中的图节点、代码、token 或格点直接成形，变化通过相邻状态、对象对应和短箭头表达，主要机制处于开放白底或中性局部范围中。

独立留出主例 H13 X-Pruner（CVPR 2023）、H28 SHE（ICML 2025）、H35 Energy-based Epistemic Uncertainty for GNNs（NeurIPS 2024）支持相同组织特征。H13 有线框分隔，H35 有局部操作范围，说明“开放”不要求完全没有框；关键是科学对象承担主要表达。H10 Before Generation, Align it! 依靠文字示例与彩色阶段块叙事，不能因其中包含 SQL 文本就判为本风格。

## 字体与最终字号：实现建议

| 角色 | 首选字体 | 字号／字重 |
|---|---|---|
| 子图与状态标题 | Times New Roman | 11.5 pt Bold |
| 对象标签／短操作名 | Times New Roman | 10 pt；操作名可 Bold |
| 字面代码内容 | Consolas | 9.5–10 pt |
| 数学 | LaTeX NewTX Math | 10.5 pt |

数学变量全部交给数学引擎。普通代码与程序行使用等宽字体；它不代替公式。原图精确字体及字号无法从 JPEG 确认，上表是执行建议。

## 配色：实现建议

| 角色 | HEX | 说明 |
|---|---|---|
| 画布 | `#FFFFFF` | 开放背景 |
| 标签、数学、主线 | `#222222` | 深色结构 |
| 中性局部范围 | `#F4F4F4` | 必要示例或背景 |
| 对象类别 A | `#C7E1D6` | 第一类对象 |
| 对象类别 B | `#CFE9B1` | 第二类对象 |
| 对象类别 C | `#EDCEBF` | 必要第三类对象 |
| 局部区别 | `#A83233` | 特殊状态／对应项，需有明确名称 |

对象填充与区别色参考 D27 的 JPEG 量化色；它们不是所有对象图共有的调色板。不要把类别色擅自解释为高低数值，也不要为满足配色表增加对象类别。

## Box、箭头与表达

token、矩阵、图、分子或状态直接用其结构呈现。单元轮廓约 0.6–0.7 pt，大小按标识文字调整；矩阵格数和节点数若为示意，不当成真实维度。操作需要封装时可用白底小框；对象组也可用括线或中性范围。没有外框仍要使名称、对象与箭头归属清楚。

主操作箭头约 0.8 pt，填充三角长 1.5 mm、底宽 1.0 mm。对象对应线约 0.55–0.65 pt，必要时开放箭头；非计算对应可用无箭头引线并标明含义。以相邻位置或行列对应减少交叉，复杂对象不能用大量连线填满画布。

## 构图

让对象状态或关系沿主要阅读方向展开，操作标签位于变化发生处。重复对象使用相同形态与尺度，变化局部强调，不变部分可共享。可以组合两个相邻例子解释机制，但输入输出和科学依赖必须完整。对象无法直接表达的复杂过程适当概括成模块；不要为了开放外观隐藏真实阶段边界。

## 可直接使用的风格提示词

> 使用 P2 开放对象机制。以研究对象的结构、状态对应和变化形成主线，操作名称放在关系发生处，必要局部范围用白底轮廓或括线。Times New Roman 标签 10 pt、状态标题 11.5 pt Bold，字面代码用 Consolas，数学用 NewTX Math。白底与深色 `#222222`，对象色可用 `#C7E1D6`／`#CFE9B1`／`#EDCEBF`，特殊对应项可用 `#A83233`。对象轮廓约 0.65 pt、主箭头 0.8 pt。对象类别、数量和连接按原文确定。
