# 三种由图库提炼的风格

**仅当用户明确指定风格，或要求使用风格库时读取本索引及相应提示词。** 用户未指定时不加载本目录，依据任务与研究内容独立构思。这里是可选的视觉表达家族，不是每次绘图必选的模板。

## 什么被验证，什么没有

这些组织特征在其他论文中重复出现，支持它们作为有适用条件的设计选项。它们不是所有顶会插图都遵守的规律，也不是互斥分类；一张图可以混合多种表达。照片／结果墙、单一统计图、无比较关系的单链等反例限制了各家族的适用范围。

这是同一观察者进行的论文间定性留出核对，不是统计意义的 k-fold 验证、独立评审者盲测或全图库频率估计。六个会议均有样本，但候选限于 `architecture/pipeline/conceptual/comparison` 元数据类别，不能外推到所有类别。

JPEG 中能观察字体类别、边界和配色关系，不能可靠识别具体字体文件、原始字号、线宽或作者的矢量色值。文档中的字体名称、pt、mm 和 HEX 是**可复现的实现建议**，不是测得的通用规律。部分填充色参考代表图的 JPEG 量化色，仅作近似起点；数学与数值语义保持原研究定义。

## 使用约定

先由任务和论文确定科学主张、重点及真实依赖，再应用用户指定的风格。保持草图必保布局、同篇论文已有约定与会议明确规范的优先级。字号、线宽和几何建议都按最终插入尺寸执行；变窄时重排而非硬缩字。普通文字保持可编辑，数学用真实 LaTeX／MathJax 衬线排版，最终 PDF 检查字体嵌入与边界。

普通字体可按用户要求替换；缺少首选字体时，衬线可回退 Times New Roman／DejaVu Serif，无衬线可回退 Arial／DejaVu Sans，并复查字宽。字体和色号不强迫研究对象采用某种数量或连接。文档只借鉴通用视觉方法，没有复制或重新分发原论文图形资产；证据中的原图版权归原作者与出版方。

示例：`使用 figure-craft，采用 P2 开放对象机制，根据论文文字制作框架图。` 只有此类明确风格请求才触发相应文档读取。最终彩色检查和可选参考图规则继续沿用主 skill，不增加灰度检查或看图配额。
